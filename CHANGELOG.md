# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows Semantic Versioning.

## [1.0.0] - 2026-08-12

### Added

* Initial Utilities package release.
* Cached main camera access through `CameraUtils`.
* Cached `WaitForSeconds` instances through `CoroutineUtils`.
* UI pointer detection utilities through `UIUtils`.
* Canvas element world position utilities through `CanvasUtils`.
* `Transform` extension methods.
* `DeleteChildren()` extension for removing all children from a `Transform`.
* Unity Package Manager support.
* Git-based package installation.
